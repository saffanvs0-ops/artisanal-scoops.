KEY FEATURES:

1. CUSTOM FLAVOUR & PRODUCT MANAGER (CMS):

   - Provide an Admin/Manager interface to add, edit, or delete ice cream items.

   - Start with 0 preset items (completely empty menu by default).

   - Each item form must include:

     * Flavor/Product Name

     * Short Description

     * Category (Scoops, Tubs, Sundaes, Sorbets, Popsicles)

     * Dietary Badges (Eggless, Organic, Vegan, Sugar-Free)

     * Image URL input or file upload field

     * Stock quantity ("X left" badge)

     * Single Price (in INR ₹)

     * Double Price (in INR ₹)

     * 500ml Tub Price (in INR ₹)



2. CARD LAYOUT (MATCHING UI SCREENSHOTS):

   - Card background: Soft cream container with subtle border radius.

   - Top image container with dietary badges overlaid on top-left and stock count badge ("X left") on bottom-right.

   - Flavor title in elegant bold serif font.

   - Description in clear muted text.

   - Serving options: Single (₹), Double (₹), and "+ Add 500ml Tub (₹)".



3. SHOPPING CART & CHECKOUT:

   - Floating cart drawer and bottom order bar.

   - Calculates Subtotal, GST (5%), and Total in INR (₹).

   - Checkout modal with order summary and customer phone number input (+91).



4. ROLE SWITCHER BAR:

   - Include a quick role switcher at the top bar for testing: Owner, Manager, Customer.

   - When in Owner or Manager mode, show "Add New Flavor" button and inline "

Edit / Delete" controls on each item card.
